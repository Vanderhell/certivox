# Security policy

Certivox provides CRC and error-correction primitives. CRC is not a
cryptographic authenticator, and Hamming/SECDED codes have bounded correction
and detection guarantees described in the API reference.

Please report suspected security-relevant defects through GitHub's private
vulnerability reporting for this repository when available. Include the
affected API, compiler/configuration, a minimal reproducer and impact. Avoid
posting an exploitable report publicly before maintainers have had a chance to
review it. No response-time or support guarantee is implied.
